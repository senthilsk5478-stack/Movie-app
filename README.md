# Multi-Region Cinema Analytics Portal 🎬

An interactive dashboard to explore 100 films from around the world, including Hollywood, Tamil, Malayalam, Telugu, Hindi and Kannada cinema.

🔗 Live app: https://movie-app-kdzvgmvcd3wdadsjwjovk6.streamlit.app/

## Features
- Search by title, director or cast
- Filters for genre, rating, duration, votes and box office
- Live KPI cards for average rating, votes and revenue
- Box Office Scale: Mega Blockbuster, Major Hit, Standard Revenue
- 5 interactive charts: top-rated films, rating vs box office, genre split, most-voted films, yearly rating trend
- Download the filtered data as CSV

## Tools Used
Python, Streamlit, Pandas, Plotly, GitHub, Streamlit Community Cloud

## Run it locally
pip install -r requirements.txt
streamlit run "Movie app.py"
